# Archived college prototype

These are preserved historical sources, not runtime modules of RecruitAI v2.
They retain their original imports and are not expected to run in this location.
The original overview and team attribution are in ../docs/LEGACY-README.md;
the original repository history is preserved locally in ../.git-history.

The v2 runtime imports only server/ and core/mcdm/, with web/ as static assets.
No code in this directory is packaged in the deployment image. The Supabase
database associated with this prototype has not been queried or modified.
